Creating Smart Number Tickets by Selecting a Wheeling System		   


To Creating Smart Number Tickets by Selecting a Wheeling System:

①.On the numbers panel, selecting your like numbers, If the number is selected will become a Red button. If you want to cancel selection, please use the mouse to click the specified number.

②. In the radio box, select Wheels Generator, In the drop-down list, select a formula.

③. Click Generate Tickets button.



Then the all tickes will be saved in the tickets panel.
