Installing SamLotto		   


1. Be sure that your system meets all of the system requirements for running SamLotto.

2. Be sure that all other open program are closed.

3. If you have enough available space on your C or other drives, recommend that you install it in the default location.

SamLotto Software System Requirement

SamLotto software program supports all 32 bit or 64 bit Windows computer systems including Windows XP, Vista, Windows 7, Windows 8, and Windows 10. You can install it on your PC, laptop, or surface.
