System Requirement		    


SamLotto requires the following minnimun requirements:

 · 486 DX 66MHz or higher PC, running Windows 95/98/ME/NT/2000/XP/Vista/Windows 7/Windows 8/Window 10.

· 512 MB RAM or higher.

· 500 MB free hard disk space.

· VGA display or higher (256 colors or more).

* If your operating system is Windows Vista or Windows 7/8, you should perform the following steps.

1. Right click on the SamLotto icon on your desktop and select Properties.

2. Select the Compatibility tab.

3. Check the box next to "Run this program as an administrator."

4. Repeat the above steps for the Update Lotto Drawing Files icon on your desktop.
