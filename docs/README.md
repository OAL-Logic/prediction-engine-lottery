# Prediction Engine Documentation

Welcome to the central knowledge base for the Prediction Engine. The documentation has been curated and organized into semantic areas to ensure that context is maintained and research is intentional.

## Directory Structure

*   **[`gemini-session/`](./gemini-session/)**
    Historical records of AI chat sessions and unstructured conversational logs.
*   **[`memory/`](./memory/)**
    Internal project memory index and context files.
*   **[`raw/`](./raw/)**
    Unstructured data, clippings, and raw analysis outputs.
*   **[`research/`](./research/)**
    Distilled, highly-curated knowledge. Includes SmartLuck systems, Numerology fundamentals, and environmental correlation reports.
*   **[`tui/`](./tui/)**
    System design and implementation specifications for the Terminal User Interface.
*   **[`versions/`](./versions/)**
    Legacy feature batches and historical version documentation.
