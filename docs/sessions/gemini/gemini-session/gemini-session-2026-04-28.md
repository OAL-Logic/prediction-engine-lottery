## 🛠️ Technical Details

### Sum Range Logic
The engine now uses an exact analytical mean and variance for the sum of $k$ numbers from a pool of $n$:
- $E[S] = k \frac{lo + hi}{2}$
- $Var[S] = k \frac{(n+1)(n-k)}{12}$
This is used to calculate the 70% "Most Probable Range" using a rational approximation of the inverse normal CDF, ensuring the core engine remains dependency-light.

### Efficiency Metric
The `odds` command uses a log-scale efficiency score:
- $Score = \frac{\log_{10}(odds)}{price}$
- This helps players identify which games offer the most "probability bang for their buck" regardless of currency or jackpot size orders of magnitude.
