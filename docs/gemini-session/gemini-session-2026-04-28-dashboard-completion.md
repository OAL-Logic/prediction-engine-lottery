- **`lottery board --view row10`:** A custom frequency map that forces a 10-column layout regardless of the native game structure.
- **Impact:** Designed specifically to detect horizontal "linear streaks" and decade-based patterns that are often obscured in standard 5-column layouts.

- **Formats:** Supports `.csv`, `.json`, and `.xlsx` (Excel) formats.
- **Impact:** Empowers power-users to take the data out of the CLI for custom manipulation in spreadsheets, Python Notebooks, or external visualization tools.
