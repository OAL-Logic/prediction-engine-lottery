### 2. Suggestion Constraints (Ideas 2 & 3)
- **`--pool` Flag:** Allows users to restrict any strategy's candidate pool to a specific subset of numbers.
- **`--key` Flag:** Guarantees that specific numbers appear in every suggested ticket, perfectly complementing the Wheeling system.

### 3. Hard Structural Filters (Idea 7)
- **`--filters` Flag:** Introduced a composable filtering system for `lottery suggest`:
    - `sum_range`: Enforces the 70% probability band.
    - `parity`: Ensures balanced even/odd ratios.
    - `breadth`: Enforces decade coverage.
    - `no_consecutive`: Rejects tickets with 4+ consecutive numbers.
    - `no_arithmetic`: Rejects obvious arithmetic sequences.
    - `birthday_bias`: Avoids tickets clustered heavily in the 1-31 range.

### 4. Co-occurrence Strategy (`copairs`)
- **Hot Pairs Strategy:** Wired up the existing correlation engine as a first-class strategy. It scores numbers based on their historical "bond strength" with the currently hottest numbers in the game.

## 🛠️ Technical Details

### Filter Implementation
Filters are implemented as a post-sampling rejection layer in `BaseStrategy.suggest`. The engine uses a resampling loop (up to 20x the requested count) to find tickets that satisfy all active predicates.
