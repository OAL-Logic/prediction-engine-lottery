- **`--test`**: Immediately evaluate the generated tickets against a result to see the prize distribution.

## 🛠️ Technical Details

### Greedy Covering Approximation
Since computing optimal covering designs (Steiner Systems) is an NP-hard problem, the engine uses a **Greedy Randomized Solver**. It prioritizes tickets that cover the largest number of remaining uncovered $t$-subsets. 

### Key Wheel Logic
The key wheel uses a reduced combinatorial space: it fixes $M$ keys and generates $C(V-M, K-M)$ combinations for the remaining slots.
