Command `scan`

The scan runs 6 layers (2pts each, max 12):
1. **Fairness** — chi-squared uniformity test
2. **Signal stability** — rolling window confidence std-dev
3. **Cluster** — K-Means draw profile (informational)
4. **Esoteric** — moon phase + solar K-index
5. **Discrimination** — can the strategy distinguish real from random?
6. **Regime** — Jensen-Shannon divergence vs full history (STABLE/DRIFT/SHIFT)

Verdicts: **GO** (≥70%) / **CAUTION** (≥40%) / **NO-GO**

Between each layer, show the veredict and some hint about the step to help validate the result.
