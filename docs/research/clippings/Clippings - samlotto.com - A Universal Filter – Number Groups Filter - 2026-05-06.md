**SamLotto lottery software** provide a very powerful filter, a lot can be done with this filter.

Today I will show you how to use it.

Many people send emails asking me to implement this function:

> i have a group of 20 numbers (1-20). I want 3-4 of these numbers in each ticket. is this possible?

Inside the advanced filters, the **Number Groups Filter** can easily complete this task!

## What is Number Groups Filter?

Determines some of the numbers and how many of these numbers are allowed to occur in a combination, If the combination does not match the set conditions will be filtered out.

How to set number groups?  
  
You can set any number combination to this filter, Like this: 27 32 34 43 52, 04-10 17 43 52, 50-59, etc. Theoretically, you can set any number of groups as a filter condition and parameter.

For example, as shown below, enter the numbers: 01 13 21 25 30 31 32 33 38 45 51, filter conditions set 1-2, Meaning the numbers 01 13 21 25 30 31 32 33 38 45 51 allow 1 or 2 number to occur in a combination If the combinations that do not match 1 or 2 will be filtered out.

## Filtering Combinations Using Number Groups Filter

Next I will explain how to use this filter.

Let’s use Powerball as an example, select 15 numbers first then generate the complete combinations, total of 3003 combinations was generated!

![[attachments/9e8a02c615963434f58ef7690c0a28c3_MD5.gif]]

The following gif animation will demonstrate how to use Number Groups Filter.

![[attachments/33bf48adbe81d4f31987cdf837c47b1e_MD5.gif]]

Checked Number Groups Filter, open the Number Groups Filter window to add number groups and filtering parameters.

We added only two number groups as filtering conditions.

The first group of numbers was randomly selected 8 numbers: 01 11 12 21 31 41 51 61.

![[attachments/952fc830203aa7b23566d1838f5e8df9_MD5.jpg]]

After selecting the number, open the filtering assistant, as shown below. The program automatically counts the past 20 draws results. In this number group in the last 20 draws, 0 times appears 12, 1 times appears 4, and 2 times also appear 4.

![[attachments/a0941e5898f572e9483b065484cc03a2_MD5.jpg]]

The second number group is set in the same way as the first one.

![[attachments/dc811ecc08fc1b6bf4d469c031064cb2_MD5.jpg]]

![[attachments/2162099b03c03f687edd32c0b76533d1_MD5.jpg]]

There is no limit to the number of such number groups that can be added, I added only two. After setting the filter conditions, click the filter button to start filtering. In the filtering report, you can see that 927 bad combinations are filtered out.

![[attachments/e2b2d5f2c81a134bb40e481d082dd954_MD5.jpg]]

## Summary

Although the Number Groups Filter can filter out a lot of bad combinations, it is not enough, if you want to filter out more combinations you have to combine them with other filters, our **lottery software** offers a lot of filters, you can test them and find the best filters for you!
