Next we will detail each advanced filter.

## 1\. Adv Number Count

This is a collection of number count filters, you can set Odd, Even, Prime, High and Low filters in this filter. For an introduction to these filters please see the article on basic filters.

## 2\. Adv Number Sum

This is a collection of number sum value filters, Number Sum, and The Unit Number Sum filters in this filter. For an introduction to these filters please see the article on basic filters.

#### High Numbers Sum and Low Numbers Sum

Determines High Numbers Sum value or Low Numbers Sum value can occur in a combination, If the combination does not match the set conditions will be filtered out.

How to calculate High Numbers Sum value or Low Numbers Sum value?  
  
All numbers are divided into two groups, this time according to whether the number is in the lower or higher half of the possible range. The groups are 1 to 34 (low) and 35 to 69 (high) for Powerball (1 to 69 numbers), after getting all the high or low numbers add the high numbers in the combination to each other.

For example, 05, 11, 14, 15, 55, 69, High Numbers Sum is 55+69=124, so High Numbers Sum value is 124. Low Numbers Sum is 5+11+14+15=45, so Low Numbers Sum value is 45.

#### Odd Numbers Sum and Even Numbers Sum

Determines Odd Numbers Sum value or Even Numbers Sum value can occur in a combination, If the combination does not match the set conditions will be filtered out.

How to calculate Odd Numbers Sum value or Even Numbers Sum value?  
  
Count all the even or odd numbers in the number combination, then add the odd numbers or even numbers in the combination to each other.

For example, 03, 08, 17, 22, 55, Odd Numbers Sum is 3+17+55=75, so Odd Numbers Sum value is 75. Even Numbers Sum is 8+22=30, so Even Numbers Sum value is 30.

#### Prime Sum

Determines Prime Sum value can occur in a combination, If the combination does not match the set conditions will be filtered out.

How to calculate Prime Sum value? Count all the Prime numbers in the number combination, then add the Prime numbers in the combination to each other.

## 3\. Successive Number Filter

For example, 02 03 19 30 31 46, 02 03 and 30 31 are all successive 2, so Successive 2 groups is 2.

How to set range of numbers? You can set this range arbitrarily, Like this: 01-10, 11-20, 21-40, 41-45 etc.

## 5\. Number Groups Filter

Determines some of the numbers and how many of these numbers are allowed to occur in a combination, If the combination does not match the set conditions will be filtered out. [[Clippings - samlotto.com - A Universal Filter – Number Groups Filter - 2026-04-28|Number Groups Filter]] is more flexible than Range Filter, any number can be used as a condition.

## 7\. Locked Nunber

This filter is very similar to Number Groups Filter, the difference is that this filter has to lock a number, and if the combination does not contain the locked number, then the combination does not participate in the filter.

Example 1, as shown below, locked number is 02, enter the numbers: 13 21 25 30 31 32 33, filter conditions set 1-2, Meaning the numbers 13 21 25 30 31 32 33 allow 1 or 2 number to occur, combinations that do not match 1 or 2 will be filtered out. If the combination does not contain the locked number 02, this combination will be ignored and will not participate in the filter.
