Today I want to show how to generate all combinations using positions.

What is Positon?

For example, for Powerball 12/23/2020 drawn numbers: 06 13 38 39 53 06, position 1 number is 06, position 2 number is 13, position 3 number is 38, position 4 number is 39, position 5 number is 53.

This feature allows you to set only which numbers appear in each position in the number combination.

We have studied a lot of data and found that there is a pattern in the numbers that appear in each position.

For example, for Powerball from 08/01/2020 to 01/20/2020 (50 draws), Please first look at the following 5 graphs, each showing the frequency analysis of numbers appearing in different positions.

With the above analysis, we can target the range of numbers for each position. Position 1 we can select from numbers 1 to 28, position 2 we can select from numbers 3 to 37, position 3 we can select from numbers 11 to 58, position 4 we can select from numbers 32 to 63, position 5 we can select from numbers 43 to 69.

After selecting numbers for each position, we have to generate all possible combinations (as shown below), so that you will win the jackpot assuming that all the numbers you selected are correct.
