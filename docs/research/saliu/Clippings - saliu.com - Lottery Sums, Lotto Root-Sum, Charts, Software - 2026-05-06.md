***Deltas***, anyone? Well, that sounds like a fancy word. It is for the alphabet letter ***D*** of the Classical Greek language (the one that educated humans in creating the Modern Civilization). ***D*** is the mnemonic for ***difference***. [**Lottery deltas**](https://saliu.com/delta-lotto-software.html) are ***differences** between adjacent lottery numbers.* For example, *delta\_1* represents the difference between the number one and the 2nd number in a lotto combination. The delta is expressed as an absolute number, not a signed number. Lotto number\_1 = 1; lotto number\_2 = 7; delta = 7 – 1 = 6 (it is never minus 6).
