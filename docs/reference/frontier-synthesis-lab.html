1. Otimização de Portfólio QUBO / Ising (Computação Quântica)

Modela a seleção global de bilhetes minimizando um Hamiltoniano com termo quadrático de repulsão entre bilhetes: H(x) = -∑ w_i x_i + λ ∑ |T_i ∩ T_j| x_i x_j. Evita apostas com dezenas sobrepostas e maximiza a área combinatorial coberta.

2. Redes Neurais em Hipergrafos (HGCN) para Coocorrência

Cada sorteio é uma hiperaresta entre as dezenas sorteadas. Embeddings contínuos de grafos aprendem atrações e repulsões latentes que modelos par-a-par tradicionais ignoram.

3. Poda de Filtros por Informação Mútua (Information Bottleneck)

Mede a entropia de Shannon e informação mútua entre os 69 filtros disponíveis, eliminando automaticamente restrições colineares e prevenindo sobreajuste (overfitting).

4. Priores Dirichlet-Multinomial com Amostragem de Thompson

Modela sorteios sem reposição de forma exata via distribuições de Dirichlet, equilibrando matematicamente o aproveitamento de dezenas quentes com a exploração de dezenas frias e atrasadas.
