**Goal:** full and abbreviated covering designs with guarantee reporting, regenerated
as our own tables (never copy the proprietary `.Wheels` binaries). **Verified source:**
Doc 04. **Depends on:** EPIC 1 (Game/k). **Phase:** 5. **Consumed by:** EPIC 3 (F3.4).

**Features:** F5.1 Full wheel · F5.2 Abbreviated wheel + guarantee · F5.3 Wheel
library storage · F5.4 Custom wheel + convert-to-wheel · F5.5 Wheeling UI.

> **Separation of concerns:** a wheel is a **letter map** (1-indexed letter combos)
> independent of the numbers; `instantiate(wheel, pool)` substitutes numbers.

---

## F5.1 — Full wheel
**User stories** — *As a player,* a full wheel of my `n` numbers gives all `C(n,k)` lines.
**Acceptance:** AC-W1. **Module:** `core/wheels/full`.

**Chain**
- **S1:** `full(k,n): Wheel` (letter combos = all k-subsets of 1..n); `instantiate(wheel, pool): Combination[]`.
- **S2:** 8/pick-6 → 28; 10 → 210; 12 → 924 (property = C(n,k)); instantiation maps letters→pool[i-1].
- **S3:** k-combination enumeration → letter combos.
- **S4:** GenerationEngine wheel mode.
- **S5:** build + instantiate an 8-number wheel; assert 28 lines.
- **Gate:** `{{ACCEPTANCE}}`=AC-W1.

---

## F5.2 — Abbreviated wheel + guarantee report
**User stories** — *As a player,* an abbreviated wheel gives the minimal lines that
guarantee a stated match tier if X of the winners are in my numbers.
**Acceptance:** AC-W2, AC-W4. **Module:** `core/wheels/abbreviated`.

**Chain**
- **S1:** `abbreviated(k,n,guarantee): Wheel` + `guaranteeReport(wheel): "if X in pool → Y lines match Z"`.
- **S2:** 8/pick-6/if-4 → **exactly 7 lines**, and for **every** 4-subset of the 8 there is ≥1 line containing all 4 (brute-force cover check). Guarantee wording matches Doc 04.
- **S3:** use published covering-design tables for common `(k,n,guarantee)`, else a greedy/ILP set-cover solver; store the resulting letter table. **Log any case where the cover is not proven minimal** (no silent claims).
- **S4:** wheel library (F5.3); GenerationEngine.
- **S5:** build the 7-line wheel; run the cover check; print the guarantee report.
- **Gate:** `{{ACCEPTANCE}}`=AC-W2/W4; **gate fails if the cover check finds an uncovered X-subset.**

---

## F5.3 — Wheel library storage + naming
**User stories** — *As the system,* I store wheels keyed by `(k, n, guarantee, variant)`
(the original `PICK-SIZE-GUARANTEE-VARIANT` convention) as our own JSON.
**Acceptance:** AC-W1/W2. **Module:** `core/wheels/library` + `data` (wheel JSON).

**Chain** — S1 `WheelLibrary { get(k,n,guarantee,variant?): Wheel; list(k): WheelMeta[] }`; S2 lookups return correct sizes; S3 JSON tables generated by F5.1/F5.2 (a build script emits them; **no proprietary files copied**); S4 available to generation UI; S5 verify a few lookups. Gate: AC-W1/W2; provenance note: tables are self-generated.

---

## F5.4 — Custom wheel + convert-tickets-to-wheel
**User stories** — *As a power user,* I define a custom wheel; and I convert an
existing ticket set back into a compact wheel structure.
**Acceptance:** AC-W3. **Module:** `core/wheels/custom`.

**Chain** — S1 `custom(letterCombos)`, `ticketsToWheel(tickets): Wheel`; S2 round-trip instantiate(custom)=given lines; convert then instantiate reproduces the set; S3 implement; S4 screen Tcustomwheel + ticket-store menu "convert to wheel"; S5 verify round-trip. Gate: AC-W3.

---

## F5.5 — Wheeling UI
**User stories** — *As a player,* I choose a wheel formula for my selected pool and
see its line count and guarantee before generating.
**Acceptance:** AC-W1..W4. **Module:** `apps/desktop` (wheel picker on S01).

**Chain** — S1 `<WheelPicker k pool onSelect/>` showing per-formula line count + guarantee; S2 (E2E) pick "if-4" → shows 7 lines + guarantee; S3 build; S4 wire to F3.4; S5 drive in app. Gate: all AC-W*.

### Epic 5 exit criteria
Full counts exact; abbreviated wheels pass the brute-force cover check; guarantee
reports truthful; all tables self-generated (no proprietary `.Wheels`).
