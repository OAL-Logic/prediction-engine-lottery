## Base Filters



The filter is a very useful function that can help us 
eliminate bad tickets. Lottery Studio supports 50 base filters. Over 90% of 
filtering methods not available in any other lottery programs. that is so easy 
to use that you don’t even need to know the algorithm of each filter.

The 
program can automatically generate the filter parameters, no need to set the 
filter parameters manually, it is all done automatically by the 
program.

3. High 
Count

Determines how many 
high numbers can occur in a combination, If the combination does not match the 
set conditions will be filtered out. How to calculate High Count? All numbers 
are divided into two groups, The groups are 1 to 34 (low numbers) and 35 to 69 
(high numbers) for Powerball (1 to 69 numbers). For example: 04 19 23 25 49, the 
high numbers: 49, so High Count=1.

4. Low Count

Mega Millions (1 to 70 numbers). For example: 04 05 17 43 52, the high numbers: 
04 05 17, so Low Count=3..

6. Number 
Sum

Determines the sum value can occur in

7. Average Value

Determines average 
value can occur in a combination, If the combination does not match the set

average value is 106/6=17.

10. Successive

Determines 
Successive numbers amount can occur in a combination, If the combination does 
not match the set conditions will be filtered out. What is the successive 
number? Count all adjacent numbers in a combination and find the group with the 
highest amount of adjacent numbers.

For example 03 04 25 26 27 43, 03 04 
and 25 26 27 are all the successive numbers, 03 04 adjacent amount is 2, and 25 
26 27 adjacent amount is 3, so Successive=3.

11.Successive 
Groups

Determines Successive Groups amount can occur in a 
combination, If the combination does not match the set conditions will be 
filtered out. What is successive number groups? Count all adjacent numbers in a 
combination and find the group amount of adjacent numbers.

For example 03 
04 25 26 27 43, 03 04 and 25 26 27 are all the successive numbers, 03 04 is a 
group and 25 26 27 is a group, so Successive Groups=2..

16. First-Last 
Distance

Determines First-Last Distance value can occur in a 
combination, If the combination does not match the set conditions will be 
filtered out. How to calculate First-Last Distance value? The value of the 
difference between the last number and the first number.

For example 11 15 17 30 41 51, the last number is 51, the first number is 
11, so the First-Last Distance value is 51-11=40.



17. Max Distance

Determines 
Max Distance value can occur in a combination, If the combination does not match 
the set conditions will be filtered out. How to calculate Max Distance value? 
The values of the difference between the all adjacent two numbers. the largest 
value is Max Distance.

For example 02, 05, 17, 19, 27, 31, the distance 
list : 3 (05-02=3), 12 (17-05=12), 2 (19-17), 8 (27-19), 4 (31-27=4), so the max 
distance is 12.

18. Average 
Distance

Determines Average Distance value 
can occur in a combination, If the combination does not match the set conditions 
will be filtered out. How to calculate the Average Distance value? The values of 
the difference between the all adjacent two numbers, all values are added 
together and finally divide by the numbers amount.

For example, 02, 05, 17, 19, 27, 31, the distance 
is 3 (05-02=3), 12 (17-05=12), 2 (19-17=2), 8 (27-19=8), 4 (31-27=4). 
(3+12+2+8+4)/5=5, so the distance average value is 5..

19.Different 
Distance

Determines Different 
Distance amount can occur in a combination If the combination does not match the 
set conditions will be filtered out. How to calculate Different Distance? The 
values of the difference between the all adjacent two numbers, remove duplicate 
values, and count the amount.

For example: 02, 05, 08, 19, 27, 31, 
the distance is: 3 (05-02=3), 3 (08-05=3), 11 (19-08=11), 8 (27-19=8), 4 
(31-27=4), remove duplicates value 3, so the different distance is 
4..

## Clean-Room Python Boilerplate

```python
from dataclasses import dataclass
from typing import Callable

@dataclass(frozen=True)
class RangeFilter:
    tag: int
    name: str
    metric_fn: Callable[[list[int]], int]
    min_val: int
    max_val: int

    def evaluate(self, ticket: list[int]) -> bool:
        val = self.metric_fn(ticket)
        return self.min_val <= val <= self.max_val

def evaluate_filter_suite(
    ticket: list[int],
    filters: list[RangeFilter],
    mode: str = "AND",
    n_of_m: tuple[int, int] | None = None,
) -> bool:
    passed = sum(1 for f in filters if f.evaluate(ticket))
    if mode == "AND":
        return passed == len(filters)
    if mode == "OR":
        return passed >= 1
    if n_of_m is not None:
        lo, hi = n_of_m
        return lo <= passed <= hi
    return True
```
